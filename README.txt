【★ 怎么换照片（三步，不用碰代码）】
1. 打开 images 文件夹，找到下表里对应的占位图
   （占位图上就写着它自己的文件名）
2. 把你的照片改成和它一样的文件名
   · 照片是 .png / .heic？先用「画图」打开 → 另存为 JPEG
   · 建议 4:3 横版；页面会自动居中裁剪，不会变形
3. 把改好名的照片放进 images 文件夹，覆盖原占位图
   → 刷新网页，立刻生效
